# SPPU AIDS Data Modeling & Visualization Practicals

A collection of **SPPU Artificial Intelligence & Data Science (AI &
DS)** practicals for **Data Modeling & Visualization**.

This repository contains simple, beginner-friendly **Python and Jupyter
Notebook** implementations of the practicals, using libraries such as
Pandas, NumPy, Matplotlib, Scikit-learn, and Statsmodels.

> 📚 Created for **learning, practical work, revision, and viva
> preparation**.

------------------------------------------------------------------------

## 📂 Practical Files

### 🔹 Lab 1 --- Data Loading, Storage and File Formats

Covers loading and working with **CSV, Excel, and JSON** files, data
cleaning, basic analysis, and visualization.

**File:** `Lab_1_Data_Loading_Storage_and_File_Formats_Simple.ipynb`

------------------------------------------------------------------------

### 🔹 Lab 3 --- Data Cleaning and Preparation

Covers basic data cleaning techniques such as handling missing values,
removing duplicates, correcting data types, feature engineering, and
preparing data for analysis.

**File:** `Lab_3_Data_Cleaning_and_Preparation.ipynb`

------------------------------------------------------------------------

### 🔹 Lab 4 --- Data Wrangling

Covers filtering, merging, handling categorical variables, aggregation,
and basic outlier handling.

**File:** `Lab_4_Data_Wrangling.ipynb`

------------------------------------------------------------------------

### 🔹 Lab 5 --- Data Visualization using Matplotlib

Covers different visualization techniques including:

-   Line plots
-   Bar charts
-   Pie charts
-   Box plots
-   Scatter plots
-   Labels, titles, and legends

**File:** `Lab_5_Data_Visualization_using_Matplotlib.ipynb`

------------------------------------------------------------------------

### 🔹 Lab 6 --- Data Aggregation

Covers grouping and summarizing data using Pandas.

Topics include:

-   `groupby()`
-   `pivot_table()`
-   Sales by region
-   Sales by product category
-   Bar charts
-   Pie charts
-   Grouped bar charts

**File:** `Lab_6_Data_Aggregation.ipynb`

------------------------------------------------------------------------

### 🔹 Lab 7 --- Time Series Data Analysis

Covers basic time-series analysis and visualization.

Topics include:

-   Date and time conversion
-   Stock-price trends
-   Moving averages
-   Seasonality
-   Correlation
-   Trading volume
-   Exponential smoothing
-   Basic forecasting

**File:** `Lab_7_Time_Series_Data_Analysis.ipynb`

## 📊 Datasets

The practicals use datasets available through **Scikit-learn
(`sklearn.datasets`)** wherever possible.

For practicals where Scikit-learn does not provide the required
real-world dataset, a simple example dataset is created using an sklearn
dataset.

This makes the notebooks:

-   Easy to run
-   Easy to understand
-   Reproducible
-   Suitable for practical demonstrations

## ▶️ How to Run

### 1. Clone the repository

``` bash
git clone https://github.com/parthraorane86/SPPU-AIDS-Data-Modeling-Visualization-Practicals.git
```

### 2. Open the repository

``` bash
cd SPPU-AIDS-Data-Modeling-Visualization-Practicals
```

### 3. Start Jupyter Notebook

``` bash
jupyter notebook
```

Open any `.ipynb` file and run the cells.

You can also open the notebooks using **Google Colab**.
